# Testvektoren

Gemeinsame JSON-Testvektoren für Metrik-Berechnungen (Normalized Power, TSS, CTL/ATL, Zonen usw.).
Die TypeScript-Implementierung (`functions/`) und die Dart-Vorschau (`lib/`) testen **beide** gegen diese Dateien,
damit sie nicht auseinanderlaufen. Format und Quellen der Referenzwerte: siehe `docs/specs/METRICS.md`.
