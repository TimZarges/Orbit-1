# Phase fortsetzen

1. Lies `AGENTS.md`, `docs/PROGRESS.md`, die aktuelle Phasendatei in `docs/phases/` und prüfe mit `git status` und `git log` den **tatsächlichen Stand** auf dem Branch.
2. Berichte mir kurz: Was ist erledigt, was fehlt noch in dieser Phase, wo ist der nächste STOPP-Punkt, gibt es uncommittete oder halbfertige Änderungen?
3. Arbeite danach wie im Skill `phase-start` weiter (Aufgaben der Reihe nach, STOPP-Punkte beachten).
